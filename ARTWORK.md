The hand and upright phone were built as a custom procedural 3D scene and rendered using Blender Cycles. The final asset is `public/assets/heus-hand-phone.png`.

The reference supplied by the user informed the smooth material style and upright presentation. It is not included in the application or archive.

The phone app interface is custom text and geometric artwork drawn by the bundled Python script. The surrounding TV interface is React and CSS. No generated image asset or external photograph is included.
